# SOP Library · Field Guide Series

![Diagrams](https://github.com/richdieu-max/sop-library/actions/workflows/diagrams.yml/badge.svg) ![Checks](https://github.com/richdieu-max/sop-library/actions/workflows/checks.yml/badge.svg)

**44 standard operating procedures · 125 architecture, flow and concept diagrams · 14 technology families**

Production runbooks from my work across Microsoft Azure, Entra ID, Intune, AWS, Red Hat Enterprise Linux, security operations, regulated (GxP) lab IT and Windows support. Every page reads directly on GitHub: what the procedure achieves, two to four diagrams (how it fits together, the procedure or decision path, and the mechanism behind it), prerequisites, the steps (console first, then PowerShell, AWS CLI or shell, then at scale), how to verify it, how to roll it back (for procedures that change something), troubleshooting, and the controls it supports.

> **Production procedures, sanitized for publication.** Every runbook here is one I run in production. Client names, hostnames, tenant IDs and ticket numbers are replaced with placeholders (Contoso, documentation IP ranges, sample change numbers). Microsoft's own built-in role, policy and app IDs are kept because the commands need them.
